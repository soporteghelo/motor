# Fuente de diseño

Lee `design-system/motor-pwa/MASTER.md` para consultar el sistema Data-Dense Dashboard completo antes de implementar un cambio visual.

Los tokens relevantes del proyecto están en `00_Config/Index.html`:

- `--ds-surface`, `--ds-surface-sunken`, `--ds-fg`, `--ds-fg-muted`
- `--ds-border`, `--ds-border-soft`, `--ds-skeleton`, `--ds-scrim`
- `--color-primary`, `--color-bg`, `--color-surface`, `--color-text`

El sistema de diseño fuente gobierna la densidad de componentes, el comportamiento responsivo, el contraste y el emparejamiento de temas claro/oscuro.
